SQL 智能助手接口手册

只凭查询平台的元数据回答两类问题：表和字段是什么、需求怎么写成可执行的 SQL。不执行查询，不返回数据。

前缀 /sql-assistant 提问 SSE 流式 更新 2026-10-08
●后端状态：已部署预发，可联调。服务地址（内网，端口 18777）找吉云飞获取。

对接步骤

  1. 打开页面：调 POST /sql-assistant/suggest，把返回的问题做成可点击的推荐。
  2. 提问：调 POST /sql-assistant/ask/stream，带前端生成的 session_id。同号追问会带上历史；新会话换一个新号即可。
  3. 渲染：过程区显示 step.label；答复直接渲染 answer.markdown；answer.follow_ups 做成追问按钮。

通用约定

项说明
身份account_hash_id，与调问数接口时传的是同一个值。助手只看得到该账号在查询平台上有权限的库表。
项目project：查询平台项目名或 project_id，字符串或数字都行，如 137 或 "新仙魔3D"。不传则由助手按问题判断。
选定表tables：「选择库表」选中的表，"库名.表名,库名.表名"（中英文逗号均可）或数组，最多 20 张。助手优先基于这些表回答，不够用时会另找表并说明原因。不选就不传。
会话session_id：前端生成，字符串或数字，最长 128 字符。同一账号下同号即同一会话，2 小时未用自动过期。
鉴权与问数接口相同：服务端开启口令时带请求头 X-Api-Token（当前未开启）。
耗时一轮通常 5–60 秒，最长 300 秒。

提问

POST/sql-assistant/ask/stream

返回 SSE 事件流。question 必填，其余字段见通用约定。

请求
{
  "question": "最近一个月每天新增用户的次留",
  "account_hash_id": "<account_hash_id>",
  "project": 137,
  "session_id": "1",
  "tables": "xianmo_an.xianmo_daily_user_dashboard,xianmo_ods_rt.user_login_log"
}

事件（按顺序）

eventdata前端怎么用
session{"session_id"}即请求里的会话号
step{"label"}过程提示，如「读取表结构：xxx」
answer见下表答复
error{"message"}失败原因，直接展示
done{"elapsed_ms"}结束

answer 字段

字段说明
markdown拼好的完整答复，直接渲染即可
kindsql 给出 SQL · metadata 回答元数据 · clarify 反问用户
sqls[]每段 SQL：title purpose sql time_window volume checks（自己排版时用）
follow_ups[]推荐追问
ddl[]用户要建表语句时附上的原文：table sql（已包含在 markdown 里）
返回示例（节选）
event: session
data: {"session_id": "1"}

event: step
data: {"stage": "tool", "label": "读取表结构：xianmo_ods_rt.user_login_log"}

event: answer
data: {"kind": "sql", "markdown": "…", "sqls": [ … ], "follow_ups": [ … ], …}

event: done
data: {"elapsed_ms": 31520}

每 15 秒有一行 : ping 心跳，忽略即可。断开连接即取消本轮。

推荐问题

POST/sql-assistant/suggest

带 session_id 且该会话上一轮有追问建议时返回追问建议（source=follow_up），否则按账号有权限的真实库表生成开场问题（source=opening）。limit 可选，默认 6。

请求
{"account_hash_id": "<account_hash_id>", "project": 137, "session_id": "1"}
响应
{"source": "opening", "questions": ["…", "…"]}

错误

开始推流之前的错误走 HTTP 状态码，响应体 {"error": "…"}；开始之后的走 error 事件。两种提示文字都可直接展示。

状态码含义
400没带身份
401口令错误
422请求体不合法（如缺 question、session_id 超长、tables 某项不是 库名.表名）
502推荐问题生成失败
503服务端未配置查询平台
